# numberle_in_python

Numberle is a game inspired from wordle which uses a simple mathemetical equation limited to 8 characters.

The user must guest the equation within 6 turns

Rules:
1. You must enter an equation with a limit of 8 characters
2. Use +, -, * and / to illustrate operations
3. You are limited  to 6 tries
4. We will display 'O' if the character is correct, 'H' if the answer is correct but in the wrong place and 'X' if the answer is wrong
5. Do not put spaces in between any of the characters
